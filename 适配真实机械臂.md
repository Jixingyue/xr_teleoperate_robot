# 如何适配真实机械臂（非仿真）

## 文档概述

本文档详细说明了如何在真实环境中集成自定义机械臂到XR遥操作系统。与仿真系统不同，真实机械臂需要处理通信协议、安全控制、硬件接口等实际问题。

---

## 系统架构

### 整体架构图

```
XR设备 (Quest 3)
    │
    ├─ TeleVuerWrapper (遥操作接口)
    │       ↓
    ├─ RobotArmController (机械臂控制器) ←── 抽象基类
    │   │
    │   ├─ UR3E_ArmController        ←── 具体实现
    │   ├─ AuboI5_ArmController      ←── 具体实现
    │   └─ YOUR_ArmController        ←── 你的实现
    │
    ├─ UniversalRobotArmIK (逆运动学)
    │       ↓
    └─ 真实机器人 (通过SDK/Socket通信)
```

### 核心组件

1. **RobotArmController**（抽象基类）
   - 定义标准控制接口
   - 管理线程安全
   - 处理关节限制

2. **具体控制器实现**
   - UR3E_ArmController：Universal Robots UR3E
   - AuboI5_ArmController：遨博i5机械臂
   - 你的自定义控制器

3. **UniversalRobotArmIK**
   - 通用逆运动学解算器
   - 基于Pinocchio和CasADi
   - 支持配置文件驱动

---

## 与仿真的关键区别

| 特性 | 仿真系统 | 真实机械臂 |
|------|----------|------------|
| **通信方式** | 直接API调用 | SDK/Socket通信 |
| **控制频率** | 240Hz+ | 10-250Hz（取决于硬件） |
| **安全机制** | 不需要 | **必须**：碰撞检测、急停、限位 |
| **状态获取** | 同步 | 异步（线程） |
| **延迟** | <1ms | 10-50ms |
| **调试** | 容易 | 需要真实硬件 |
| **错误处理** | 可忽略 | **必须**：硬件保护 |

## 步骤 1：理解抽象基类

### 1.1 RobotArmController 类结构

```python
# teleop/robot_control/robot_arm_basic.py

class RobotArmController(ABC):
    """
    所有机械臂控制器的抽象基类
    """
    
    def __init__(self, robot_type: str, motion_mode: bool = False):
        """
        初始化控制器
        
        Args:
            robot_type: 机器人类型（必须与config/robot_config.yml匹配）
            motion_mode: 是否启用运动模式（人形机器人）
        """
        # 从配置文件加载参数
        self.config = config_loader.get_robot_config(robot_type)
        self.num_joints = len(self.config["arm_joints"])
        self.joint_limits = self.config["joint_limits"]
        
        # 控制参数
        self.control_dt = 1.0 / 250.0  # 控制周期
        self.velocity_limit = 20.0     # 速度限制
        
        # 状态缓冲区（线程安全）
        self.state_buffer = DataBuffer()
        self.command_buffer = DataBuffer()
        
        # 线程锁
        self.ctrl_lock = threading.Lock()
    
    # ========== 必须实现的抽象方法 ==========
    
    @abstractmethod
    def _init_robot_connection(self) -> bool:
        """初始化机器人连接"""
        pass
    
    @abstractmethod
    def _subscribe_motor_state(self):
        """订阅电机状态（在独立线程中运行）"""
        pass
    
    @abstractmethod
    def _publish_motor_command(self):
        """发布控制命令（在独立线程中运行）"""
        pass
    
    @abstractmethod
    def _go_home_implementation(self):
        """实现回到初始位置的逻辑"""
        pass
    
    # ========== 标准接口方法 ==========
    
    def get_current_dual_arm_q(self) -> np.ndarray:
        """获取当前关节角度"""
        return np.array([
            self.state_buffer.GetData().motor_state[joint["index"]].q 
            for joint in self.joint_arm_index
        ])
    
    def get_current_dual_arm_dq(self) -> np.ndarray:
        """获取当前关节角速度"""
        return np.array([
            self.state_buffer.GetData().motor_state[joint["index"]].dq 
            for joint in self.joint_arm_index
        ])
    
    def ctrl_dual_arm(self, q_target, tauff_target):
        """设置目标关节角度和力矩"""
        with self.ctrl_lock:
            self.q_target = q_target
            self.tauff_target = tauff_target
    
    def ctrl_dual_arm_go_home(self):
        """回到初始位置"""
        self._go_home_implementation()
    
    def start(self):
        """启动控制器（连接+启动线程）"""
        if self._init_robot_connection():
            self._start_control_threads()
    
    def stop(self):
        """停止控制器（回原点+断开连接）"""
        self.ctrl_dual_arm_go_home()
        self._stop_control_threads()
```

### 1.2 关键设计模式

**双线程模型**：
- **订阅线程**：高频读取机器人状态（250Hz+）
- **发布线程**：控制频率发送命令（10-250Hz）

**线程安全**：
- 使用 `DataBuffer` 类提供线程安全的数据访问
- 使用 `threading.Lock()` 保护共享资源

```python
#!/usr/bin/env python3
"""
自定义机械臂控制器
"""

import numpy as np
import threading
import time
import socket  # 或者你的机器人SDK
import logging_mp
from robot_control.robot_arm_basic import (
    RobotArmController, MotorState, LowState, DataBuffer
)

logger_mp = logging_mp.get_logger(__name__)


class YourRobot_ArmController(RobotArmController):
    """
    自定义机械臂控制器
    继承自RobotArmController抽象基类
    """
    
    def __init__(self, robot_ip: str = "192.168.1.100", 
                 robot_port: int = 30003, 
                 motion_mode: bool = False):
        """
        初始化控制器
        
        Args:
            robot_ip: 机器人IP地址
            robot_port: 通信端口
            motion_mode: 是否为运动模式
        """
        # 调用父类初始化（必须）
        super().__init__("YOUR_ROBOT_NAME", motion_mode)
        
        # 自定义参数
        self.robot_ip = robot_ip
        self.robot_port = robot_port
        
        # 初始化连接
        if not self._init_robot_connection():
            raise RuntimeError(f"无法连接到机器人 {robot_ip}:{robot_port}")
        
        # 启动控制线程
        self._start_control_threads()
        
        logger_mp.info("机械臂控制器初始化完成")
    
    def _init_robot_connection(self) -> bool:
        """
        初始化机器人连接
        
        Returns:
            bool: 连接是否成功
        """
        try:
            logger_mp.info(f"连接到机器人: {self.robot_ip}:{self.robot_port}")
            
            # 示例：Socket连接
            self.robot = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            self.robot.connect((self.robot_ip, self.robot_port))
            
            # 或者：使用机器人SDK
            # from your_robot_sdk import RobotSDK
            # self.robot = RobotSDK()
            # self.robot.connect(self.robot_ip, self.robot_port)
            
            # 测试连接：获取当前位置
            test_pos = self._get_current_pos()
            if test_pos is not None:
                logger_mp.info(f"连接成功，当前关节角度: {test_pos}")
                return True
            else:
                logger_mp.error("无法获取机器人状态")
                return False
                
        except Exception as e:
            logger_mp.error(f"连接失败: {e}")
            return False
    
    def _subscribe_motor_state(self):
        """
        订阅电机状态数据
        在独立线程中高频运行
        """
        while self._subscribe_running:
            try:
                # 1. 获取当前关节状态
                current_pos = self._get_current_pos()
                if current_pos is not None:
                    self.current_joint_angles = current_pos
                    
                    # 2. 计算关节速度（简单差分）
                    if hasattr(self, '_last_positions'):
                        dt = self.control_dt
                        self.current_joint_velocities = (
                            current_pos - self._last_positions
                        ) / dt
                    self._last_positions = current_pos.copy()
                
                # 3. 更新数据缓冲区（线程安全）
                state = LowState(self.num_joints)
                
                for i, motor_state in enumerate(state.motor_state):
                    motor_state.q = self.current_joint_angles[i]
                    motor_state.dq = self.current_joint_velocities[i]
                
                self.state_buffer.SetData(state)
                
                # 4. 控制循环频率
                time.sleep(self.control_dt)
                
            except Exception as e:
                logger_mp.error(f"订阅状态失败: {e}")
                time.sleep(0.1)
    
    def _publish_motor_command(self):
        """
        发布电机控制命令
        在独立线程中运行
        """
        while self._publish_running:
            try:
                start_time = time.time()
                
                # 1. 获取目标值（线程安全）
                with self.ctrl_lock:
                    q_target = self.q_target.copy()
                    tauff_target = self.tauff_target.copy()
                
                # 2. 检查关节限制
                for i, (angle, (min_limit, max_limit)) in enumerate(
                    zip(q_target, self.joint_limits)
                ):
                    if angle < min_limit or angle > max_limit:
                        logger_mp.warning(
                            f"关节{i+1}角度{angle:.3f}超出限制"
                            f"[{min_limit:.3f}, {max_limit:.3f}]"
                        )
                        q_target[i] = np.clip(angle, min_limit, max_limit)
                
                # 3. 应用速度限制（重要！防止突变）
                q_target = self.clip_arm_q_target(q_target, self.velocity_limit)
                
                # 4. 发送控制命令
                if np.any(q_target != self._last_sent_target):
                    self._send_joint_command(q_target)
                    self._last_sent_target = q_target.copy()
                
                # 5. 控制频率
                elapsed = time.time() - start_time
                sleep_time = max(0, self.control_dt - elapsed)
                time.sleep(sleep_time)
                
            except Exception as e:
                logger_mp.error(f"发布命令失败: {e}")
                time.sleep(0.1)
    
    def _get_current_pos(self) -> np.ndarray:
        """
        获取当前关节角度
        
        Returns:
            np.ndarray: 关节角度数组，失败返回None
        """
        try:
            # 示例：从Socket读取
            # data = self.robot.recv(1024)
            # pos = parse_joint_data(data)
            
            # 或者：使用SDK
            # pos = self.robot.get_joint_positions()
            
            # 示例返回
            pos = np.zeros(self.num_joints)
            return pos
            
        except Exception as e:
            logger_mp.error(f"获取关节角度失败: {e}")
            return None
    
    def _send_joint_command(self, joints: np.ndarray):
        """
        发送关节角度命令
        
        Args:
            joints: 目标关节角度数组
        """
        try:
            # 示例：通过Socket发送
            # command = format_joint_command(joints)
            # self.robot.send(command.encode())
            
            # 或者：使用SDK
            # self.robot.move_joints(joints)
            
            logger_mp.debug(f"发送命令: {joints}")
            
        except Exception as e:
            logger_mp.error(f"发送命令失败: {e}")
    
    def _go_home_implementation(self):
        """
        回到初始位置
        """
        logger_mp.info("回到初始位置...")
        
        # 设置目标为零位
        with self.ctrl_lock:
            self.q_target = np.zeros(self.num_joints)
            self.tauff_target = np.zeros(self.num_joints)
        
        # 等待到达
        max_attempts = 100
        tolerance = 0.05  # 5度容差
        
        for attempt in range(max_attempts):
            current_q = self.get_current_dual_arm_q()
            if np.all(np.abs(current_q) < tolerance):
                logger_mp.info("已到达初始位置")
                break
            time.sleep(0.05)
        else:
            logger_mp.warning("未能完全到达初始位置")


# ============================================================================
# 工厂函数（可选）
# ============================================================================

def create_arm_controller(robot_type: str, **kwargs):
    """
    工厂函数：根据机器人类型创建控制器
    """
    robot_type_upper = robot_type.upper()
    
    if robot_type_upper == "YOUR_ROBOT_NAME":
        return YourRobot_ArmController(**kwargs)
    # ... 其他机器人类型
    else:
        raise ValueError(f"不支持的机器人类型: {robot_type}")
```

**关键参数**：

1. **arm_joints**:

## 步骤 4：实现通信协议

### 4.1 Socket 通信示例（UR机器人）

```python
import socket
import struct

class UR3E_ArmController(RobotArmController):
    def _init_robot_connection(self) -> bool:
        try:
            self.robot = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            self.robot.connect((self.robot_ip, 30003))  # UR实时端口
            
            # 测试连接
            test_pos = self._get_current_pos()
            return test_pos is not None
            
        except Exception as e:
            logger_mp.error(f"连接失败: {e}")
            return False
    
    def _get_current_pos(self):
        """UR机器人：解析实时数据包"""
        try:
            # UR机器人发送1116字节的状态包
            data = self.robot.recv(1116)
            
            # 关节角度位于252-300字节（6个double）
            pos = struct.unpack('!6d', data[252:300])
            return np.array(pos)
            
        except Exception as e:
            logger_mp.error(f"获取状态失败: {e}")
            return None
    
    def _send_joint_command(self, joints):
        """UR机器人：发送URScript命令"""
        try:
            # 新建连接发送命令（UR的设计）
            s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            s.settimeout(0.1)
            s.connect((self.robot_ip, 30003))
            
            # 构建URScript命令
            joints_str = ",".join(map(str, joints))
            command = f"movej([{joints_str}], a=0.1, v=0.1, t=3, r=0)\n"
            
            s.send(command.encode())
            s.close()
            
        except Exception as e:
            logger_mp.error(f"发送命令失败: {e}")
```

```python
from .aubo_sdk import Auboi5Robot, RobotErrorType

class AuboI5_ArmController(RobotArmController):
    def _init_robot_connection(self) -> bool:
        try:
            # 初始化SDK
            Auboi5Robot.initialize()
            self.robot = Auboi5Robot()
            
            # 创建上下文
            handle = self.robot.create_context()
            logger_mp.info(f"SDK句柄: {handle}")

                logger_mp.error("连接失败")
                return False
            
            # 初始化机器人
            self.robot.project_startup()
            self.robot.enable_robot_event()
            self.robot.init_profile()
            
            # 设置速度和加速度限制
            joint_maxvelc = (2.596, 2.596, 2.596, 3.110, 3.110, 3.110)
            joint_maxacc = (6.92, 6.92, 6.92, 6.92, 6.92, 6.92)
            self.robot.set_joint_maxvelc(joint_maxvelc)
            self.robot.set_joint_maxacc(joint_maxacc)
            
            return True
            
        except Exception as e:
            logger_mp.error(f"SDK初始化失败: {e}")
            return False
    
    def _get_current_pos(self):
        """使用SDK获取当前位置"""
        try:
            waypoint = self.robot.get_current_waypoint()
            return np.array(waypoint['joint'])
        except Exception as e:
            return None
    
    def _send_joint_command(self, joints):
        """使用SDK发送命令"""
        try:
            # 检查角度变化（避免频繁发送）
            if np.all(np.abs(self.current_joint_angles - joints) < 0.05):
                return
            
            # 发送关节运动命令
            joints_tuple = tuple(joints)
            self.robot.move_joint(joints_tuple)
            
        except Exception as e:
            logger_mp.debug(f"发送命令失败: {e}")
```

```python
#!/usr/bin/env python3
"""
自定义机械臂遥操作主程序
"""

import numpy as np
import time
import argparse
from televuer import TeleVuerWrapper
from robot_control.universal_robot_arm_ik import UniversalRobotArmIK as ArmIK
from robot_control.your_robot_arm import YourRobot_ArmController
import logging_mp

logger_mp = logging_mp.get_logger(__name__)

if __name__ == '__main__':
    parser = argparse.ArgumentParser()
    parser.add_argument('--robot-ip', type=str, default='192.168.1.100')
    parser.add_argument('--frequency', type=float, default=60.0)
    args = parser.parse_args()
    
    # 1. 初始化XR接口
    tv_wrapper = TeleVuerWrapper(
        binocular=False,
        use_hand_tracking=False,
        return_state_data=True
    )
    
    # 2. 初始化机械臂控制器
    arm_ctrl = YourRobot_ArmController(robot_ip=args.robot_ip)
    
    # 3. 初始化IK解算器
    arm_ik = ArmIK(robot_type='YOUR_ROBOT_NAME')
    
    try:
        logger_mp.info("系统启动，按Ctrl+C退出")
        
        # 回到初始位置
        arm_ctrl.ctrl_dual_arm_go_home()
        
        while True:
            start_time = time.time()
            
            # 获取遥操作数据
            tele_data = tv_wrapper.get_motion_state_data()
            
            # 获取当前机械臂状态
            current_arm_q = arm_ctrl.get_current_dual_arm_q()
            current_arm_dq = arm_ctrl.get_current_dual_arm_dq()
            
            # 求解逆运动学
            sol_q, sol_tauff = arm_ik.solve_ik(
                right_wrist=tele_data.right_arm_pose,
                current_lr_arm_motor_q=current_arm_q,
                current_lr_arm_motor_dq=current_arm_dq
            )
            
            # 控制机械臂
            if sol_q is not None:
                arm_ctrl.ctrl_dual_arm(sol_q, sol_tauff)
            
            # 控制频率
            elapsed = time.time() - start_time
            sleep_time = max(0, (1 / args.frequency) - elapsed)
            time.sleep(sleep_time)
            
    except KeyboardInterrupt:
        logger_mp.info("正在退出...")
    
    finally:
        arm_ctrl.stop()
        logger_mp.info("程序已退出")
```

```python
def check_collision(self, right_arm_pose):
    """
    检查目标位姿是否在安全范围内
```

### 2. 缓存优化

```python
class CachedIK:
    def __init__(self, arm_ik):
        self.arm_ik = arm_ik
        self.cache = {}
        self.cache_size = 100
    
    def solve_ik(self, target_pose, current_q):
        # 使用位置作为缓存键
        key = tuple(target_pose[:3, 3].round(3))
        
        if key in self.cache:
            return self.cache[key]
        
        # 求解IK
        sol_q, sol_tauff = self.arm_ik.solve_ik(
            right_wrist=target_pose,
            current_lr_arm_motor_q=current_q
        )
        
        # 更新缓存
        if len(self.cache) >= self.cache_size:
            self.cache.pop(next(iter(self.cache)))
        self.cache[key] = (sol_q, sol_tauff)
        
        return sol_q, sol_tauff
```
